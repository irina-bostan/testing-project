# Testing Project with Copilot

This is a simple project to test GitHub Copilot's capabilities in generating code snippets 
and completing code based on comments and existing code.

## Features
- Spring boot application that represents a school catalog
- Database schema in schema.sql
- Database migration using flyway
- In-memory database for testing
- API contract in openapi.yaml file
- All pojos are generated from the openapi.yaml file
- Pojos are mapped to DB entities using mapstruct library
- RESTful API endpoints
- Basic CRUD operations
- Spring boot tests
- Unit tests
- Dockerfile for containerization
